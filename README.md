# 부산 자율운항보트 경진대회 — LiDAR 장애물 회피 + YOLO 표지 인식

> 2025 동계 자율운항보트 기초교육 및 경진대회 · 팀 **4세이돈** · **우수상 (12팀 중 3위)**

코스는 부표 구간을 통과한 뒤, 중반에 지정된 색·도형 표지를 찾아 통과하는 구성이었습니다. 부표 회피는 LiDAR 클러스터링으로, 표지 인식은 카메라 + YOLOv8n(ONNX)으로 처리했습니다.

## 시스템 구성

```
LiDAR (/scan) ──┐
                ├─▶ navigation_node ──▶ /actuator/thruster/percentage (추진 %)
IMU   (/imu)  ──┘        (0.5초 주기)   ├─▶ /actuator/key/degree       (서보 각도)
                                        └─▶ /actuator/rgbwled/color    (상태 LED)

Camera ──▶ YOLOv8n (ONNX Runtime, CPU) ──▶ 표지 색·도형 판별 ──▶ (중반 표지 구간 주행에 사용)
```

## 주행 로직

1. **전방 시야 추출** — LiDAR 전체 스캔 중 정면 기준 160°만 잘라 사용합니다.
2. **노이즈 제거** — 0.1m 미만, 10m 초과, `inf`/`NaN` 값을 버립니다.
3. **DBSCAN 클러스터링** (`eps=0.5`, `min_samples=7`) — 점들을 장애물 단위로 묶고, 노이즈 점(label −1)은 제외한 뒤 클러스터별 중심점을 계산합니다.
4. **조향 결정** — 장애물이 있으면 회피각을 계산해 서보에 보내고, 없으면 직진(0°)하며 흰색 LED를 켭니다.
5. **표지 구간** — 부표 구간을 지난 뒤 YOLO로 지정된 표지를 인식해 그 표지를 통과하도록 주행합니다. 

## 객체 인식 (YOLOv8 → ONNX)

코스 중반의 표지 미션을 위해, 부표와 색·도형 표지(circle·cross·triangle × red·green·blue)를 탐지하는 모델을 아래 흐름으로 만들고 SBC에 탑재했습니다.

1. **데이터** — Roboflow에서 라벨링한 데이터셋 (학습 426장 / 검증 52장, 10클래스)
2. **학습** — Colab T4 GPU에서 YOLOv8n 학습 (100 epochs, 640px, batch 16)
3. **변환** — 학습한 PT파일을 ONNX로 export
4. **배포** — SBC에서 ONNX Runtime(CPU)으로 실시간 추론
5. **후처리** — 모델 원시 출력 `(1, 14, 8400)`을 직접 파싱해 박스 좌표 변환, 신뢰도 0.5 필터링, NMS(IoU 0.4) 적용
